# Contribuir com o ONDA

Relate um problema por issue com versão do ONDA, Windows e passos reproduzíveis. Se o problema for de mídia, inclua um link público quando puder e o log sem cookies, tokens, senhas ou caminhos pessoais.

Para alterações de código, execute a suíte descrita em `Onda/README.md`, descreva o comportamento alterado e envie um pull request. Evite incluir executáveis, downloads, ambientes Python, histórico ou configurações locais no Git.

Contribuições de código ao projeto devem ser compatíveis com GPL-2.0-only. Ferramentas e bibliotecas externas mantêm suas próprias licenças.
