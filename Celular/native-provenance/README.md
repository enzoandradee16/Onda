# Histórico do fornecedor anterior

Este diretório documenta os binários youtubedl-android 0.18.1 usados antes da reconstrução. Eles foram substituídos e não fazem parte do APK alpha.2 preparado agora. A pendência registrada no inventário histórico foi resolvida substituindo essas ferramentas por uma construção própria, com fontes, receitas e hashes em [nativebuild](../nativebuild/README.md).

Os arquivos upstream-* são documentos históricos do fornecedor anterior; não descrevem os executáveis atuais. Consulte nativebuild/NATIVE_ARTIFACTS.json para a composição atual.
