# Identificadores de ferramentas

Ícones próprios do ONDA para distinguir ferramentas na interface; não são reproduções oficiais dos logotipos dos projetos. SVGs editáveis e PNGs de 96 px são gerados por `empacotamento/generate_tool_icons.py` usando Qt, já presente no ambiente de desenvolvimento Windows.

PC e Android usam os mesmos PNGs. Os nomes e os estados acessíveis continuam em texto; a identificação não depende apenas de cor ou imagem. Não há download de ícones durante o uso.
