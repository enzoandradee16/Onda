# Pacotes do ONDA 1.2.8

- Windows x64: portátil e instalador.
- Android: APKs ARM64 e x86_64, versão 1.2.8, código 36.
- Código-fonte do aplicativo e fontes de terceiros.

Extraia todo o ZIP portátil antes de abrir Onda.exe. Para instalação no Windows, execute o instalador. No Android, escolha o APK compatível com o aparelho.

Consulte RELEASE_NOTES.md para as novidades, VALIDACAO.md para os resultados de validação e SHA256SUMS.txt para conferir a integridade dos arquivos.
