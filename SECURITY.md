# Segurança

Esta é uma versão beta, sem auditoria independente de segurança. Não abra issues públicas com vulnerabilidades que exponham contas, dados pessoais ou credenciais. Use o recurso privado de relato de vulnerabilidade do GitHub se estiver habilitado; caso contrário, solicite um canal privado sem publicar os detalhes sensíveis.

Nunca inclua cookies.txt, arquivos DPAPI, tokens, configurações ou histórico em relatórios. Downloads e links podem conter arquivos não confiáveis. Os executáveis desta beta não possuem assinatura digital.

O escopo de manutenção é a versão mais recente. Atualizações dos extratores podem ser necessárias quando as plataformas mudarem.
