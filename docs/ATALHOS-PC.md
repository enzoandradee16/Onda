# Atalhos de teclado no PC

Abra **Atalhos** no topo da janela ou pressione **F1**. A lista inclui os comandos novos e os que já existiam.

| Atalho | Ação |
| --- | --- |
| Ctrl+1 … Ctrl+8 | Abrir aba pela posição atual |
| Ctrl+Tab / Ctrl+Shift+Tab | Ir para a próxima aba / aba anterior |
| Ctrl+L | Abrir Links e focar o campo de links |
| Ctrl+J | Abrir a Fila |
| Ctrl+H | Abrir o Histórico |
| Ctrl+F | Focar a pesquisa da aba atual ou abrir Pesquisar músicas |
| Ctrl+Enter | Baixar agora na aba Links |
| Ctrl+Shift+Enter | Adicionar links à fila sem iniciar |
| F5 | Iniciar downloads na aba Fila |
| Shift+F5 | Parar downloads em andamento |
| Ctrl+R | Tentar novamente os itens selecionados da fila |
| Alt+↑ / Alt+↓ | Mover itens selecionados da fila para cima / baixo |
| Alt+Home | Priorizar itens selecionados da fila |
| Alt+V | Alternar Compacto / Completa na Fila ou Histórico |
| Ctrl+Shift+Delete | Limpar a fila |
| Ctrl+O | Abrir a pasta de downloads |
| Ctrl+, | Abrir configurações |
| Ctrl+M | Abrir janela de metadados |
| Ctrl+Shift+L | Ver detalhes dos downloads |
| Ctrl+Shift+E | Ver falhas da fila |
| F1 | Mostrar atalhos de teclado |
| Alt+A | Selecionar todos os itens da Fila ou Álbuns e playlists |
| Delete / Backspace | Remover itens quando a lista da fila está focada |
| Ctrl+roda do mouse | Alterar tamanho dos cards da Fila ou Histórico |
| Shift+F10 | Abrir opções da lista focada |

Os atalhos de posição seguem a ordem personalizada das abas. Ctrl+F usa a pesquisa de Álbuns e playlists ou Histórico quando essa aba está ativa; nas demais, abre Pesquisar músicas. Enter normal continua inserindo novas linhas em Links.

Controles de iniciar, repetir, reordenar e limpar só atuam na aba Fila e não interceptam campos de edição. Shift+F5 para os downloads a partir de qualquer aba da janela principal. Janelas de configurações, metadados e outros diálogos mantêm seus próprios comandos; os atalhos da janela principal não atuam por trás delas. As ações seguem as mesmas regras dos botões existentes.

A referência interna está disponível em português, inglês e espanhol. Não é necessário recompilar ou instalar o Android para usar estes atalhos exclusivos do PC.

Ctrl + ↑ / Ctrl + ↓: rolar a página atual para cima ou para baixo, uma tela por vez.

Ctrl + A: selecionar todos os itens na Fila, Histórico ou Álbuns e playlists. Em campos de edição, mantém a seleção de texto.
